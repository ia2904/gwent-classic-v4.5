# Gwent-classic-v4.5

A browser remake of the original Gwent minigame from The Witcher 3: Wild Hunt.<br/>Click [here](https://ia2904.github.io/gwent-classic-v4.5/) to play.

Restored some neutral cards and factions that weren't in version 4.0.
Some factions are based on the great work by [Novigrad Tavern](https://www.ebay.com/usr/novigrad_tavern) This remake is an attempt to implement the cards they designed (with some minor differences, though)..

## Improvements
Restored some neutral cards and factions that weren't in version 4.0. 
Fixed several bugs, added visual effects for Hero cards and the "Clear Weather" effect. Replaced YouTube with a local music system, added a skip track button (shuffled) and new styles, changed the initial background image and text, and improved card borders. Adapted the game visual styles and implemented device vibration for a fully responsive mobile experience. Additionally, the Android APK build has been included in the Releases section.

### Operations included with the keyboard:

**"E"** starts the game<br />
**"X"** uses or modifies the leader card<br />
**"Q"** closes the card explanation windows<br />
**"Space"** passes the round<br />
**"Enter"** plays the cards<br />
**Arrows** select cards on the carousel
